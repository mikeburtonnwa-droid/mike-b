# Workflow seeds

Copy a seed into an agent conversation and fill in its fields. A seed expresses the task; linked skills supply reusable guidance. If the agent cannot access a linked file, attach that file or paste the relevant contents.

| Seed | Use when |
| --- | --- |
| [Design workflow](design-workflow.md) | A recurring task needs a repeatable process |
| [Run workflow](run-workflow.md) | You already have a specification and actual inputs |
| [Improve workflow](improve-workflow.md) | A completed run reveals a specific failure or friction |
