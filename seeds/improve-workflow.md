# Improve a workflow from a real run

Status: draft

```text
Review this workflow: [specification or seed].
Run evidence: [inputs, actual output, and tool results where relevant].
Expected outcome: [what should have happened].
Observed problem: [failure or unnecessary effort].

Identify the instruction, missing context, tool limitation, or evaluation gap
that best explains the problem. Distinguish observed facts from hypotheses.
Make the smallest useful revision and explain how it addresses the evidence.
Preserve unrelated behavior and existing authorization boundaries.
Propose a regression case and, if execution is available and authorized, run it.
Record actual results separately from expected results. If there is insufficient
evidence for a change, identify the next observation needed.
```
